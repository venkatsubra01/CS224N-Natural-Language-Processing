# CS224N (Natural Language Processing with Deep Learning) Assignments

This repository contains the following completed assignments for Stanford's CS224N course, Winter 2021 (A1, A2, and A3) and Winter 2023 (A4 and A5) by Venkat Subramanian

## Assignments:
- **Assignment 1 (Winter 2021):** Explores the foundations of word embeddings in Natural Language Processing (NLP), focusing on both count-based and prediction-based word vector models. Here, I implemented and analyzed word vectors and reflected on their properties and biases.
- **Assignment 2 (Winter 2021):** Implements the foundational algorithms behind the word2vec model, focusing on the skip-gram architecture and two loss functions: naive softmax and negative sampling. The assignment also includes building and testing a generic stochastic gradient descent (SGD) optimizer.
- **Assignment 3 (Winter 2021):** Explores the implementation of a transition-based dependency parser using neural networks. I built the core parsing algorithm, implemented minibatch parsing, and trained a feed-forward neural network to predict parsing transitions.
- **Assignment 4 (Winter 2023):** An implementation of a Seq2Seq Neural Machine Translation (NMT) model.
- **Assignment 5 (Winter 2023):** Pretrain, finetune, and evaluates a GPT-1-esque model, while also extending it through a more efficient attention mechanism.
